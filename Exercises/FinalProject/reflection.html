Final Project Reflection: Movie Finder App

The main function of my final project is to serve as a movie explorer app to help people discover new movies based on search results, what is popular currently, and what is highly rated. Users can search for a movie by entering words into the search box, and The Movie Database (TMDB) API to find movies with the word(s) the user searched. Clicking on a movie card displays the movie's release date, rating, and an overview.The goal of this project is to provide people with a concenient way to searh for movies and find trending and highly rated movies as well without having to search an overwhelmingly large collection of films.


To create this project, I used HTML, CSS, and JavaScript. The HTMl includes elements such as header, main, and section for easy accessibility. Using CSS allowed me to create custom properties for consistent theming. I also used what I learned from the Flexbox lessons to create responsive layouts. I also incorporated some smooth hover animations and transitions to make the app more interesting and dynamic. The JavaScript played an integral role in fetching portions of the API for asynchronous data retrieval. Here, I also used what I learned from my final project creation in my CSCI 1302 Software Developement class to create event listeners for all the interactive elements used.


Overall, this project was very fun to create, and I am happy with how it turned out! I enjoyed implementing concepts I learned in class throughout the semester as well. While it was challenging to get each element to work while making sure it looked good to the user, I think this project was rewarding and fun to complete, beginning to end!
